# Project Governance

Path Protocol is currently maintained by Eric Silver of ArgentQuest. The
maintainer sets product direction, protects the deterministic gameplay and
licensing contracts, reviews contributions, manages releases, and administers
the hosted service.

## Decisions

- Bugs, proposals, and design questions begin in GitHub Issues or Discussions.
- Small, reversible improvements may proceed through a focused pull request.
- Gameplay, architecture, persistence, dependency, security, and asset-license
  changes require discussion before implementation.
- Decisions favor player safety, deterministic behavior, accessibility,
  maintainability, and redistribution rights over feature volume.

## Pull requests

Outside contributions require the configured review and all required automated
checks. Because the project currently has one maintainer, branch protection
allows the administrator to merge a maintainer-authored pull request without an
independent approval. The administrator bypass should be used only after every
required quality, browser, and security check passes; failed or pending checks
must not be bypassed.

## Maintainer growth

Regular contributors may be invited to triage issues or maintain focused areas
after demonstrating constructive participation, respect for project contracts,
and reliable review judgment. Write access is granted deliberately and may be
removed to protect users or the project.

All participation is governed by [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
Security reports follow [`SECURITY.md`](SECURITY.md).
