# Changelog

Notable changes to Path Protocol are documented here. The project follows
[Semantic Versioning](https://semver.org/) once a version is published.

## Unreleased

### Added

- Personal About page with project history, open-source invitation, GitHub,
  Theme Workshop, suggestions, and LinkedIn links.
- Public contribution, security, support, and community templates.

### Changed

- GitHub Actions use immutable action revisions, bounded runtimes, and
  cancellation of superseded runs.
- Production deployment documentation now matches the Node/Express container
  that serves both the optimized application and Theme Workshop APIs.

### Security

- CodeQL, Dependabot security updates, secret scanning, and push protection are
  enabled for the public repository.
