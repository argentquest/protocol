# Path Protocol

After years of vibe coding business applications and CMS platforms, Eric Silver decided to build something completely different: a browser game inspired by an idea from his son, Kieran.

With approximately **six hours of hands-on effort over 36 hours**, that idea became **Path Protocol**—a fast, precision-based obstacle course where players guide a token, avoid hazards, collect rewards, use power-ups, and chase a better score.

## Built with AI-assisted development

The game was developed through an iterative workflow:

**Idea → Questions → Architecture → Sprints → Code → Tests → Deployment**

The primary development tools were **OpenCode** and **ChatGPT 5.6 with Medium reasoning**, supported by React, Vite, PixiJS, WebGL, Howler.js, SVG, JSON, Docker, and Nginx.
