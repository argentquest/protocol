# Third-Party Software and Media

This file records third-party dependencies and asset provenance for Path
Protocol V3. Exact installed versions must be updated from `package-lock.json`
when a dependency is added or upgraded.

Required end-user attribution and executable-distribution cautions are
summarized in [`NOTICE.md`](NOTICE.md). Preserve that notice in source and
packaged distributions.

`--enable-gpl`. The production server uses the pinned `ffmpeg-static` runtime

upstream source locations for each platform binary. Anyone distributing the
runtime container or another packaged build must preserve those materials and
verify the corresponding-source obligations for the exact binary shipped. The
project's MIT License does not relicense that executable.

## Dependency and asset rules

- Do not add software or media with an unknown or incompatible license.
- Do not rely on a package registry page as the only license record; retain the
  upstream project and license identity.
- Update exact dependency versions after installation.
- Record modified third-party assets as modified and preserve required
  attribution.
- Record generated assets and the tool or process that created them.
- Do not copy third-party demo assets merely because they are bundled with a
  library.
- Complete the final license audit before the V3 release is marked ready.
