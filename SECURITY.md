# Security Policy

## Supported version

Security fixes target the current `main` branch and the production deployment
at <https://app.inkandquill.io/protocol/>.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature for this repository or email
[esilver@argentquest.com](mailto:esilver@argentquest.com).

Include the affected route or component, reproduction steps, impact, and any
suggested mitigation. Please avoid accessing other users' data, disrupting the
hosted service, or retaining uploaded files during research.

Eric Silver of ArgentQuest will acknowledge reports as promptly as practical,
coordinate remediation, and credit reporters who want public recognition.
