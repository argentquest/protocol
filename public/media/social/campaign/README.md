# Path Protocol Community Campaign Media

These images support the open-source community launch documented in
[`docs/marketing/LAUNCH_STRATEGY.md`](../../../../docs/marketing/LAUNCH_STRATEGY.md).
They were generated on August 16, 2026 with OpenAI's built-in image-generation
tool, using Path Protocol home and gameplay screenshots as visual references.
Final exports were resized onto a dark solid background and saved as optimized
JPEG files.

## Final prompt set

All prompts requested the existing dark navy, cyan, white, purple, and amber
visual identity; accurate short typography; no people, child name, URL,
third-party logo, or watermark; and used the current game screenshots only as
brand and subject references.

1. **Social preview:** Create a polished 2:1 open-source launch image with the
   exact text “PATH PROTOCOL,” “PLAY • BUILD • CONTRIBUTE,” and “OPEN SOURCE •
   MIT,” placing the title left and an isometric precision arena right.
2. **Origin story:** Create a sincere 4:5 personal indie-project poster with the
   exact story “AN IDEA FROM MY SON,” “BUILT TO LEARN,” and “OPENED TO
   EVERYONE,” connected by a route through a blueprint arena.
3. **Participation infographic:** Create a vertical three-part explainer with
   the exact headings “PLAY,” “BUILD,” and “CONTRIBUTE,” and the descriptions
   “100 PRECISION LEVELS,” “THEMES + COURSES,” and “OPEN SOURCE • MIT.” A
   correction pass removed unintended extra readable text from a code panel.
4. **Theme Workshop:** Create a square authoring-system illustration with the
   exact text “BUILD YOUR OWN PROTOCOL,” “THEME WORKSHOP,” “DESIGN • TEST •
   SHARE,” and “OPEN SOURCE,” showing modular walls and obstacle transform cues.
