# Celestial Foundry proof-of-concept

Celestial Foundry demonstrates theme-level PNG texture overrides while keeping
the source-controlled SVG library as the mandatory fallback. It overrides 29
gameplay visuals and inherits all three arena outlines and all audio.

Selected art comes from the CC0 packs recorded in `THIRD_PARTY_LICENSES.md` and
`PublicMedia/README.md`. Runtime copies retain their registered theme-neutral
filenames; no collision geometry is derived from these images.
